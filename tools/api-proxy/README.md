# VeoBible API Proxy

Audio editor media also streams directly through signed GET/HEAD links under `/v1/audio-projects/<edition>/<book>/media` and `original-media`. Grants bind the book, edition, output environment, original-recording metadata and dashboard origin. Only audio files inside the owned book folders are served, with path traversal and symlink checks; no full project snapshot is required to read a recording after restart. Downloads retain their audio filename and content type. Browser grants cannot authorize project edits, synthesis or other control requests. Restart this proxy and its child service before deploying the dashboard's audio media change; no new credentials are needed.

Local HTTP proxy based on the example configuration. Starts only `video-project-api`, passes its API token and service configuration without forwarding tunnel credentials, and listens on `127.0.0.1:8420`; the child API uses `127.0.0.1:8422`. Control routes, including `/health`, require the private `API_TOKEN` shared with the dashboard. Browser media GET/HEAD requests instead accept short-lived HMAC-signed grants, scoped to one project, version, passage, format, environment, and dashboard origin. The dashboard issues and refreshes these grants without exposing the API token; media streams directly through the tunnel, bypassing its Worker.

Copy `.env.example` to `.env`, set a random 32+ character `API_TOKEN` and `DASHBOARD_ORIGINS`; run `pnpm start:api-proxy` from the repository root. `WORKING_DIR` defines the shared base directory passed to the video API, which appends its `SHORTS_DIR_NAME` and `LONGS_DIR_NAME` directory names. A crash in the child process stops the proxy. Streaming and Range headers are preserved. Media grants support CORS and downloads, expire after one hour, and cannot authorize generation or queue requests. Grants are stripped from forwarded query strings and proxy logs. Restart the proxy before deploying dashboard changes that use direct media links. Termination signals stop both processes.

In production, install `cloudflared`, configure a named tunnel pointing to `http://127.0.0.1:8420`, set `CLOUDFLARE_TUNNEL_TOKEN` in `tools/api-proxy/.env`, and run `pnpm tunnel:api-proxy`. No tunnels are created or published automatically.

Registered namespaces: `/v1/jobs`, `/v1/projects`, `/v1/analyze`, `/v1/queue`, `/v1/bible-versions`, `/v1/video-project-proposals`, and `/v1/local-models`. `/health` aggregates video availability. To add another API, register its process in `index.mjs` and its routes in `proxy.mjs`; the same tunnel serves both.

Include `https://dash.veobible.com` in `DASHBOARD_ORIGINS` alongside the local origins, and restart `pnpm start:api-proxy` after changing this setting. Audio generation validates the dashboard callback origin against this list before queuing work; a missing production origin rejects generation even when listing and editing projects work.

See [the dashboard README](../../apps/dashboard/README.md). `pnpm --dir tools/api-proxy test` verifies authentication, routing, forwarding, and upstream disconnection handling.

Both tokens are read exclusively from `tools/api-proxy/.env`. Environment overrides, the legacy `TUNNEL_TOKEN` alias, and tunnel command-line options are not supported. The child API ignores local credential settings and requires startup through the proxy.

`VIDEO_SILENCE_DETECTION=0` disables optional FFmpeg silence searches for estimated passage and verse cut boundaries (the default). Set it to `1` to enable them. ForcedAligner analysis is independent and remains available with silence detection disabled. Restart the proxy after changing the variable.

The video API keeps video renders, project narration, and project alignment execution in a separate task process; the generation queue and job state stay in the HTTP process. Editor inspections use another process, so neither rendering nor analysis blocks the HTTP event loop. Audio probes and optional silence analyses are limited to two concurrent subprocesses per process, deduplicated and cached by source file identity. Playback normalization has its own two slots in the HTTP process, independent of render normalization. Cold audio still requires normalization before streaming; this is not a guarantee of constant latency under machine-wide resource exhaustion.

Silence detection changes the baseline estimates used by relative waveform offsets. After changing this setting, rerun ForcedAligner and review existing manual cuts before rendering projects whose offsets were saved with the previous setting. Saved settings are never discarded automatically.

Voice-provider selection lives in the dashboard's Settings page. The video API dispatches Chatterbox or Qwen3-TTS Base in the corresponding isolated Python environment; this proxy keeps its existing routes, authentication and child-process behavior. See [voice-generator setup](../voice-generator/README.md#qwen3-tts-base) before selecting Qwen. The local-model inventory includes both Qwen Base sizes without loading or downloading models.

All model workers and the local-model inventory inherit the standard shared Hugging Face cache (`~/.cache/huggingface/hub` by default). The proxy does not select a private model cache. Models downloaded once are reusable by other applications under the same user and visible with `hf cache ls`.

CosyVoice 3 Base/RL are local voice alternatives for English and Spanish. From the repository root, install using `python3.12 tools/voice-generator/setup-cosyvoice.py --download`. Their isolated runtime uses the shared Hugging Face cache; `VIDEO_COSYVOICE_TTS_PYTHON` and `VIDEO_COSYVOICE_SOURCE` override installation locations. Voice and style selection remain independent from the synthesis provider.

Audio editor progress uses authenticated POST `audio-projects/<edition>/<book>/updates` session cursors and a separate `content` request. These are control routes and require the private shared token; media grants cannot authorize them. Unchanged inspections do not hydrate or serialize a project. New dashboard generations negotiate incremental `patch-v1` callbacks; older callbacks continue to send full snapshots, and stale patch cursors recover with a full snapshot. Restart this proxy and its child service before deploying the matching dashboard, after active generations finish.
