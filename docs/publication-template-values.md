# Plantillas de publicación

Copia cada bloque en Ajustes → Plantillas de publicación del formato y del idioma correspondientes, y guarda esa pestaña. No se insertan valores automáticamente en la base de datos.

Estas plantillas reproducen los textos anteriores. Facebook es una nueva propuesta equivalente a YouTube: antes no se generaba un archivo para esta red. Los videos largos ya no generan Instagram.

Variables: `{title}` es el título del video, `{reference}` la referencia del pasaje, `{version}` el nombre de la versión, `{passage}` todos los versículos seleccionados (uno por línea) y `{hashtags}` los hashtags calculados según el idioma, libro, temas del pasaje, formato y red social. La dirección del sitio es texto editable. Una plantilla vacía omite su archivo. Se añade un salto de línea final al archivo.
